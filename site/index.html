Secure Job Envelope

A portable, signed, post-quantum-encrypted record for a manufacturing job as it moves between buyer and shop. The two demos run the real reference library in your browser — no server, nothing leaves the page — and the full desk app is the interactive workbench. Each demo installs as an offline PWA.

Guide Claims & conformance
Lifecycle & binding

Compose → quote → amend → award

A quote binds to the exact revision it priced. Amend the spec and the hash moves, so the quote goes stale; the award locks the traveler at L2 Executable. Watch the state machine enforce it.

Encrypted exchange

Seal it so only the shop can open it

Post-quantum, forward-secret sealing with ML-KEM-1024 and a one-time prekey. The wire artifact is ciphertext; tamper, wrong-key, prekey-burn and downgrade attacks are all refused — live.

The full desk

Open the interactive workbench →

The complete browser desk: compose a traveler, bind and award quotes, mint a passphrase-encrypted post-quantum identity, and seal or open an encrypted .sje envelope. The same app, exported static — all state stays in your browser.

Everything you see is computed locally with the same modules shipped in the library, the Rust CLI and the MCP server. The demos never transmit a traveler; the “encrypted exchange” seals and opens entirely within this one tab.
