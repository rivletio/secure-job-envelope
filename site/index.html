Secure Job Envelope

A Secure Job Envelope is an open format for sending a manufacturing job package between a buyer and a shop. The package is a traveler: the part, material, quantity, drawing revision, dates, quotes, and the award. Shops seal that record into an encrypted .sje file and send it over whatever channel they already use. The format is Apache 2.0. It is not a shop operating system and not a marketplace.

When a buyer orders custom parts, two things are easy to get wrong: the price has to match the exact spec, and the details shouldn't leak on the way to the shop. A price is always pinned to one exact spec, and what's sent is encrypted.

The specification and reference implementations are on GitHub.

What a traveler looks like

This is the job record that gets sealed into an encrypted .sje envelope. It is a trimmed copy of the CNC bracket example in the repository. 

{
  "spec": "sje/0.1.0",
  "traveler_id": "tvl_example01",
  "revision": 1,
  "buyer": {
    "name": "Northline Equipment",
    "city": "Reno",
    "region": "NV"
  },
  "part": {
    "family": "CNC bracket",
    "part_number": "NL-BRK-4410",
    "description": "Mounting bracket, brushed, deburred",
    "drawing_rev": "C",
    "material": {
      "spec": "6061-T6",
      "form": "plate",
      "thickness_mm": 6.35
    },
    "qty": {
      "target": 250,
      "breaks": [100, 250, 500]
    },
    "processes": ["laser", "cnc-mill", "deburr"],
    "finish": "brushed",
    "tolerances": "±0.13 mm unless noted"
  },
  "need_by": "2026-10-30"
}

Full example: examples/bracket.traveler.json
